# Badabym

Одностраничный адаптивный сайт городского сообщества Badabym. Статический HTML, без сборки и зависимостей.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий на GitHub, например `badabym`.
2. Загрузите в корень репозитория `index.html` и `README.md` (кнопка **Add file → Upload files** подойдёт).
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, затем ветку `main` и папку `/(root)`, сохраните.
5. После публикации ссылка появится в разделе Pages. Обычно адрес выглядит как `https://ВАШ-ЛОГИН.github.io/badabym/`.

Для бесплатного GitHub Pages репозиторий должен быть публичным на плане GitHub Free. Сайт и его содержимое будут доступны всем в интернете.

## Перед запуском

Название Badabym и числа на странице сейчас используются как концепция-пример. Проверьте, что описание и статистика соответствуют вашей организации. Кнопка «Написать нам» ведёт на `hello@badabym.org` — замените адрес на актуальный, если он отличается.
